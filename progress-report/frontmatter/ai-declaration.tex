\addsec{Declaration of AI Use}

\begin{guidance}[Required -- see the Handbook, Use of AI]
Every assessed submission must include this statement. State whether AI
tools were used; if so, which tools, for what purpose and in which sections.
Permitted uses are research assistance, proofreading, simple code assistance
(marked in the code) and data-analysis support. Generating the content of
the report is not permitted. Check the \enquote{Use of AI} section of the
AE1 assessment brief.

This file contains two versions. \textbf{Option A} (no AI used) is active.
If you used AI tools, comment out option A and remove the \texttt{\%} signs
in front of option B, then adapt the list to what you actually did.
\end{guidance}
