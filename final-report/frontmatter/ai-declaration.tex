\addchap{Declaration of AI Use}

\begin{guidance}[Required -- see the Handbook, Use of AI]
Every assessed submission must include this statement, placed immediately
after the acknowledgements. State:
\begin{itemize}
  \item whether AI tools were used or not;
  \item which tools (e.g.\ ChatGPT, GitHub Copilot, Grammarly);
  \item for what purpose (e.g.\ proofreading, literature search, boilerplate code);
  \item in which sections or files.
\end{itemize}
Permitted uses are research assistance, proofreading, simple code
assistance (marked in the code) and data-analysis support. Generating the
content of the report is not permitted. Check the \enquote{Use of AI}
section of the AE2 assessment brief, and keep only one of the two
versions below.
\end{guidance}

% --- Version 1 ------------------------------------------------------
No AI tools were used in the preparation of this report.

% --- Version 2 ------------------------------------------------------
AI tools were used in the following capacity during this project:
\begin{itemize}
  \item ChatGPT was used to help identify relevant literature sources for
    \cref{ch:literature}; all sources were read and are cited directly.
  \item Grammarly was used for proofreading throughout the report.
  \item GitHub Copilot was used to generate boilerplate code for the data
    logging module (\cref{lst:logger}, lines 3--6). All logic and algorithms
    were developed independently.
\end{itemize}
