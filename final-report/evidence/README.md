Save the PDF evidence for the appendices here; it is included automatically:

- `dse-assessment.pdf`  – DSE self-assessment, HSE checklist (required)
- `ethics-release.pdf`  – ethics release from the Solent Ethics App (required)
- `gra01.pdf`           – GRA01 risk assessment (required if practical work was carried out)
- `gantt.pdf`           – full Gantt chart (optional, Appendix A)

In final mode, a missing DSE assessment or ethics release causes a
"REQUIRED EVIDENCE MISSING" warning; a missing GRA01 or Gantt chart is left out.
