\chapter{Digital Evidence}
\label{app:digital}

\begin{guidance}[Handbook, Digital Submission Requirements]
Your design files, code, simulations and data are submitted alongside the
report on SOL, organised in folders with a README at the top level. This
appendix tells the marker what is in the submission. A template for the
README is provided in the template repository (\texttt{README-evidence.md}).
\end{guidance}
